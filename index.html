WORKSPACE SETTINGS

AI provider configuration

Set your AI provider key as a Vercel environment variable. Never paste secrets into this browser interface.

Checking server configuration…

Environment variable: OPENROUTER_API_KEY. You can also set OPENROUTER_MODEL. The deterministic rules engine works without an API key.

Data & privacy

Review history, guideline settings and asset metadata are stored in this browser's local storage in this starter version. They are not synchronized across devices or users. Avoid storing confidential content on shared devices. AI mode sends the submitted content and brand profile to your configured AI provider.
